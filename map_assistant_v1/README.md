# 智能一张图 - AI地图助手

基于 Qwen3 的智能

## 🌟 核心特性

- ✅ **自然语言地图控制** - 通过对话直接操作地图
- ✅ **智能地名识别** - 自动识别并定位地标
- ✅ **多种地图操作** - 标记、圆形、多边形、图层切换
- ✅ **实时地图响应** - AI生成的地图命令立即执行
- ✅ **完整保留原有功能** - 时间查询、网页抓取、代码执行
- ✅ **前后端分离架构** - RESTful API接口
- ✅ **现代化Web界面** - 响应式设计，流畅交互

## 快速开始

### 后端启动

```bash
cd map_assistant/backend
pip install -r requirements.txt
python main.py
```

后端将在 http://localhost:8000 启动

### 前端启动

```bash
cd map_assistant/frontend
npm install
npm start
```

前端将在 http://localhost:3003 启动

## 故障排除

### 连接错误 (ERR_CONNECTION_REFUSED)

如果前端显示连接错误，请检查：

1. **后端服务是否运行**
   ```bash
   cd map_assistant/backend
   python main.py
   ```
   应该看到：`INFO: Uvicorn running on http://0.0.0.0:8000`

2. **端口是否被占用**
   ```bash
   lsof -i :8000  # 检查8000端口
   ```

3. **防火墙设置**
   确保本地8000端口未被防火墙阻止

4. **API地址配置**
   检查前端 `src/App.jsx` 中的 `API_BASE_URL` 设置

### 离线模式

当后端服务不可用时，前端会自动进入离线模式：
- 显示连接警告图标
- 使用默认建议列表
- 禁用聊天功能直到连接恢复

## API接口

- `GET /` - 健康检查
- `POST /chat` - 发送聊天消息，支持地图命令
- `POST /chat/stream` - 流式聊天响应
- `GET /suggestions` - 获取建议提示

### 地图命令响应格式

```json
{
  "response": "已在地图上标记北京天安门广场",
  "messages": [...],
  "map_commands": [
    {

        "lat": 39.9043,
        "lng": 116.4074,
        "title": "天安门广场",
        "popup": "中华人民共和国首都北京的标志性广场"
      }
    }
  ]

```

## 🛠️ 技术实现

### 地图工具集成

- **MapTool**: 核心地图操作工具，支持标记、视图、图层等操作
- **LocationSearchTool**: 地名查询工具，内置中国和国际主要城市数据库
- **智能命令生成**: Qwen3根据自然语言自动生成地图操作代码

### 支持的地图操作

1. **add_marker** - 添加地图标记
2. **set_view** - 设置地图视图
3. **clear_markers** - 清除所有标记
4. **switch_layer** - 切换地图图层
5. **add_circle** - 添加圆形区域
6. **add_polygon** - 添加多边形区域
7. **fit_markers** - 适应标记范围

### 内置地理数据库

支持以下地点的智能识别：
- 中国主要城市：北京、上海、广州、深圳、杭州、南京等
- 知名地标：天安门广场、东方明珠塔、西湖等
- 国际城市：纽约、伦敦、巴黎、东京、悉尼等

## 配置说明

- 后端配置在 `backend/main.py` 中的 `llm_cfg`
- API密钥和模型配置可根据需要修改
- 地理数据库在 `backend/tools/map_tool.py` 中可扩展

## 部署建议

1. 后端可使用 Docker 容器化部署
2. 前端构建后可部署到静态服务器
3. 建议使用 Nginx 作为反向代理
4. 生产环境需要配置HTTPS
