淮河(竹竿河入淮口至桃花岛段)航道疏浚及岸线整治工程位于息县县城渡淮大桥处，施工总工期 24 个月。疏浚整治淮河干流长 2.89 公里，其中渡淮大桥以上长度2公里、渡淮大桥以下长度0.89公里，桩号 ${ \mathrm { K } } 0 + 0 0 0 -$ ${ \mathrm { K } } 2 { + } 8 9 0 $ 。该工程施工可产生弃土 574.60 万立方米，经处置后，可回收利用砂石资源总量 543.97 万立方米，其中砾石 61.36 万立方米、河砂 482.61万立方米。该段最低通航水位按 $9 5 \%$ 保证率，取 31.5m ，水深 2.5m ，航道设计底标高 29.0m ，疏浚边坡坡比为 1:4。水上部分包括切滩段陆上土方开挖，陆上土方工程均在堤内施工，受水位影响较小。施工采用 $1 \mathrm { m } ^ { 3 }$ 挖掘机配 8t 自卸汽车或铲运机挖运，分层开挖及堆置，以便弃土合理利用。水下部分采用绞吸式挖泥船施工，局部河段采用抓斗船配合施工。 根据工程进度计划，2023 年度疏浚河段为标段五、标段六、标段七范围，河道桩号为 $\mathrm { K } 1 + 8 2 5 ~ \mathrm { K } 2 { + } 8 9 0$ ，计划完成疏浚土方量 216.46 万 $\mathrm { m } ^ { 3 }$ ，可利用砂石量 204.92 万 $\mathrm { m } ^ { 3 }$ 。
