豫商城砂许〔2023〕第 05 号许可采砂区域（李湖开采区）位于灌河上石桥镇李湖村可采区（GHK5）范围内，桩号 $\mathrm { K } 3 8 + 3 2 0 \sim \mathrm { K } 3 9 + 4 0 0$ ，长度 1080m ，面积 17.35 万 $\mathrm { m } ^ { 2 }$ ，采砂期限为 2023 年 10 月 11 日至 2024 年06 月 07 日，许可开采总量为 120.0 万 $\mathrm { m } ^ { 3 }$ ，年度采砂控制总量 192.0 万吨。该开采区位于灌河商城县和固始县交界处，该河段左侧属固始，右侧属商城。河道左岸有过历史采砂作业，左岸滩地、河槽较浅；右岸滩地、河槽为原始地貌，且滩地较高。为避免该段河道左岸凹岸冲刷形成险工，故将该河段右岸开采深度适当加深。该河段右岸滩地高程 $2 8 . 2 \substack { - 3 6 . 8 \mathrm { m } }$ ，该开采区控制开采底高程 $2 4 . 0 4 \sim 2 3 . 5 0 \mathrm { m }$ ，开采区边线以坡脚保留 15m 预留保护距离，开采最陡边坡控制在 1:5 以内。采砂作业方式为水采，批复采砂机具包括采砂船 8 艘（泵功率 380KW），运砂船 4 艘，装载车 11 台。
