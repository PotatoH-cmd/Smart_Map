淮河干流在信阳市境内流经平桥区、浉河区、罗山县、息县、潢川县、淮滨县、固始县等 7 个县区，长度约 363.5 公里，超过淮河长度的 1/3。淮河干流岸线利用项目主要包括渡口、码头、桥梁、取水、线路、其他六种类型，存在点多、线长、面广的空间分布特征，采用传统排查手段效率低下且容易产生遗漏，利用时效高分辨率遥感影像结合河道管理范围线数据对信阳市淮河干流岸线利用情况进行遥感解译可以有效提高排查效率。 本次解译共发现淮河干流疑似岸线利用项目 114 个，具体情况如表 3.3-1所示，详细信息见文末附表 1《河南省淮河干流涉河建设项目统计表》。解译完成的疑似岸线利用项目由信阳市各级水行政主管部门根据现场实际情况开展认定与清理整治工作。 表 3.3-1 淮河干流疑似岸线利用项目汇总表 序号 县区 渡口 码头 其他 桥梁 取水 水利工程 线路 总计 1 固始县 9 2 1 3 3 0 0 18 2 淮滨县 5 5 2 6 6 0 3 27 3 潢川县 1 0 0 1 3 0 0 5 4 罗山县 0 0 0 4 1 0 3 8 5 平桥区 1 0 0 10 6 0 2 19 6 泖河区 0 0 0 3 1 1 0 5 7 息县 2 1 1 4 22 1 1 32 8 总计 18 8 4 31 42 2 9 114
