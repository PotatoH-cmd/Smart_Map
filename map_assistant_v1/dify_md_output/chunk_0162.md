河南省袁湾水库库底特殊清理工程通过坝址以水库库底原河槽（光山县境内）进行清理，为水库建成后开展水产养殖、旅游开发奠定基础，同时开辟光山县特殊干旱年份应急备用水源，延长水库死库容淤泥年限，提高水库综合开发利用价值。 本次库底特殊清理工程主要建设内容及规模：对袁湾水库上游坝脚线以上 450m 至光山县与新县交界处（桩号 $2 2 + 4 9 4 - 2 7 + 1 7 8$ 段）库区原河槽进行清理，长度为 $4 . 7 2 4 \mathrm { k m }$ ，清理始端距水库大坝上游坝脚线 450m 为安全距离，设计断面根据现状河道断面情况进行下挖清理，土方开挖 630.18万 $\mathrm { m } ^ { 3 }$ ，去除剥离层后含砂料共计 521.53 万 $\mathrm { m } ^ { 3 }$ ，经处置后可利用砂石资源量 407.1 万 $\mathrm { m } ^ { 3 }$ （实方），其中净砂量 349.79 万 $\mathrm { m } ^ { 3 }$ （堆积方），砾石量 131.14万 $\mathrm { m } ^ { 3 }$ （堆积方）。两侧边坡坡比采用 1:3，设计底宽 $1 0 3 \sim 3 3 7 \mathrm { m }$ ，设计清理底高程 $4 9 . 0 7 ~ 5 3 . 8 9 \mathrm { m }$ 。根据工程施工难度及作业量，工程计划工期分 3个年度共 14 个月。
