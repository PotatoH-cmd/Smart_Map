（1）现场监测 通过现场实地查看，潢川县白露河 BLHK2#三星采砂场可采区开采活动主要位于水下，开采活动未对采区周围河岸环境造成影响。开采砂石通过船只运送至采区下游临时堆砂点，开采结束后船只在码头集中停靠，现场生态修复工作基本到位。 ![](images/b7e7baa9316abacd05d5f6619245290bf9299a783d2b30a858057abff4ffd3c1.jpg) 图 5.4-1 三星砂场现场照片 ![](images/a22575fffd6068e60a0b7d2d1afeb691fab1e85e766e5c96eb8b3be56077148e.jpg) 图 5.4-2 三星砂场临时堆砂点 # （2）无人机航测 采砂监管测量人员对豫潢砂许〔2023〕第 01 号采砂区域进行了无人机航空摄影测量，叠加 2023 年度规划批复范围（桩号 $\mathrm { K } 1 8 \substack { + } 1 1 2 \sim \mathrm { K } 2 0 \substack { + } 1 8 6$ ）进行评估分析，开采作业主要位于采区中上游区域，未发现超范围开采问题，开采区现场生态修复基本到位。 ![](images/d659705903b195e7a01562dd908c4c3812ef5817d6fd0961fa6f268031884d4e.jpg) ![](images/aea18b7616530e262189a18ea9100913116ba529307a7995b315e21aa1122fcd.jpg) 图 5.4-3 潢川县三星砂场无人机正射影像 # （3）无人船水下测量 根据批复文件和 2023 年度实施方案，开采后控制高程为 41.98m-42.93m 。通过无人船单波束声呐测量采区水下地形，测量成果显示局部区域高程略低于开采控制高程，主要位于提砂作业区，存在提砂区域修复不到位问题。 ![](images/3e03a3ac7c0691c01b3bf88636ed42c8b7525fd39b2fe03b4ad4cb5bc99eace3.jpg) 图 5.4-4 潢川县三星砂场无人船测量成果
