豫商城砂许〔2023〕第 06 号许可采砂区域（范围孜开采区）位于灌河上石桥镇范围孜村可采区（GHK4）范围内，开采区桩号 $K 2 2 + 4 6 0 \sim$ ${ \mathrm { K } } 2 3 { + } 4 0 0 { \mathrm { ~ } }$ ，长度 940m ，面积 14.45 万 $\mathrm { m } ^ { 2 }$ ，采砂期限为 2023 年 10 月 11 日至 2024 年 6 月 7 日，许可开采总量为 50.0 万 $\mathrm { m } ^ { 3 }$ ，年度采砂控制总量 80.0万吨。开采区位于商城县上石桥镇周寨大桥上游，该河段局部河槽较深，河道岸线参差不齐，河道两侧滩地较多，开采区外两侧有零星林地，该段河道采砂尽量减少开采深度，主要以平整岸线为目标进行采砂作业，该河段滩地高程 $4 4 . 2 \sim 4 7 . 8 \mathrm { m }$ ，控制开采底高程 40.03～39.56m，开采区边线以坡脚保留 15m 预留保护距离，采砂作业方式为水采，开采最陡边坡控制在 1:5 以内。采砂作业方式为水采，批复采砂机具包括采砂船 6 艘（泵功率 380KW），运砂船 3 艘，装载车 3 台。
