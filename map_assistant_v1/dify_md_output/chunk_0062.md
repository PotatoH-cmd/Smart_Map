豫罗砂许〔2023〕第 06 号采区位于 SH4 可采区范围内，开采企业为罗山县宝鑫发展投资有限责任公司，SH4 可采区位于楠杆镇邵塆村、李寨村、高店乡闫河村。桩号： $1 1 + 9 0 0 \sim 1 2 + 9 5 0 , 1 3 + 0 5 0 \sim 1 5 + 1 6 0$ ，左右岸均在罗山县境内。本年度桩号 $1 3 \substack { + 0 5 0 } \sim 1 5 \substack { + 1 6 0 }$ ，长 2110m ，宽 $6 6 \sim 1 0 8 \mathrm { m }$ ，开采前河底高程约 $4 0 . 5 ~ 4 5 . 1 { \mathrm { m } }$ ，控制开采高程 $4 4 . 0 \sim 4 4 . 6 \mathrm { m }$ （仅采河滩部分），年度采砂控制总量 57.05 万吨。开采区边线以距岸坡保留 $6 0 ~ 1 3 0 \mathrm { m }$ 安全距离及河流中心线控制，起始端按规划比降 1:4 坡比控制进行开挖至控制开采底高程。开采作业方式为水采，批复的作业机具有 3 艘采砂船（泵功率 350KW），2 台装载车。
