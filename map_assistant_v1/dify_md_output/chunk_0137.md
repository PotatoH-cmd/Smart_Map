息县淮河干流桃花岛至息县枢纽段河道整治工程位于息县濮管区、八里岔乡，治理范围为西起桃花岛南道入口 ${ \mathrm { K 0 + 0 0 0 } }$ ，东至息县枢纽上游${ \mathrm { K } } 4 { + } 5 3 0$ ，治理淮河干流长约 4.53 公里，为保护 G230（原 S213）公路桥不受本工程影响，公路桥上游 614 米至下游 200 米河段暂不实施，疏浚淮河干流长约 3.72 公里，工程施工总工期按 24 个月控制。该工程施工可产生弃土 458.81 万立方米，其中水上部分 121.33 万立方米，水下部分337.48 万立方米。经处置后，可回收利用砂石资源总量 264.62 万立方米,其中砾石 28.66 万立方米、河砂 235.96 万立方米。 根据现状河势，并考虑息县枢纽大闸宽度、弯道布置、征地红线等，G230（原 S213）公路桥上段河道疏浚底宽按 270m 控制，由于上段左岸为桃花岛险工，本次工程疏浚避开桃花岛工，疏浚底高程为 29.00m ，并与上游河段平顺连接，下段河道疏浚底宽按 300m 控制，疏浚底高程为27.00m ，与息县枢纽闸前河底设计高程一致，右岸开挖边坡距淮河险工控制在 10m 范围。
