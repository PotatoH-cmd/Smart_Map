基于协同解译平台，利用 2023 年度第三季度具有高分辨率、高精度的真彩色遥感影像对信阳市市级河流的疑似“乱建、乱采、乱占、乱堆”及妨碍河道行洪问题进行遥感解译，共解译疑似问题 116 个，其中疑似碍洪问题 7 个，疑似“四乱”问题 109 个（疑似乱采问题 7 个、疑似乱堆 17个、疑似乱建 73 个、疑似乱占 12 个）。这些问题中包括 99 处新增解译问题和 17 处历史问题，历史问题主要包括 2021 年河南省河长办下发的全省疑似“四乱”问题清单、2022 年水利部下发的碍洪问题、2021-2022 年省智慧巡河监管项目中未完成整改或整改不彻底的问题。信阳市 2023 年度分河流及县区的解译疑似“四乱”及碍洪问题汇总情况分别如下表所示。 表3.4-1 信阳市 2023年遥感解译疑似“四乱”及碍洪问题汇总表（按河流统计） 序号 河流名称 碍洪 乱采 乱堆 乱建 乱占 总计 1 淮河(含淮河故道) 1 1 9 11 3 25 2 洋河 2 0 0 1 0 3 3 白露河(含白露河分洪道) 0 0 1 4 0 5 4 春河 0 0 0 2 1 3 5 泺河 0 0 2 7 0 9 6 东双河 1 0 1 2 0 4 7 杜河 0 0 0 3 1 4 8 史河 0 0 0 1 0 1 9 灌河 2 1 3 6 0 12 10 史灌河 0 0 0 5 1 6 11 潢河 0 1 0 10 1 12 12 泼陂河 0 0 0 2 0 2 13 晏家河 0 0 0 4 0 4 14 闾河 0 0 0 1 0 1 15 寨河 0 0 0 2 2 4 16 大洪河 1 4 0 0 2 7 17 竹竿河 0 0 0 4 0 4 18 小潢河 0 0 1 8 1 10 总计 7 7 17 73 12 116 表3.4-2 信阳市 2023年遥感解译疑似“四乱”及碍洪问题汇总表（按政区统计） 序号 政区 乱占 乱建 乱堆 乱采 碍洪 总计 1 泖河区 1 5 1 0 2 9 2 平桥区 3 8 10 0 2 23 3 罗山县 1 16 2 0 0 19 4 光山县 3 16 0 1 0 20 5 新县 0 1 0 0 0 1 6 商城县 0 6 2 1 1 10 7 固始县 1 11 1 0 1 14 8 潢川县 1 5 0 0 0 6 9 淮滨县 2 2 1 4 1 10 10 息县 0 3 0 1 0 4 总计 12 73 17 7 7 116
