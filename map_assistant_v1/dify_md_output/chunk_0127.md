固始县史河故道（夹河）区域综合整治工程范围上游至夹河固陈路桥，下游至蒋集排涝闸，两岸至夹河老堤防，河道整治长度 $1 0 . 5 \mathrm { k m }$ 。其中的河道疏浚及岸线整治工程部分弃土方量 202.52 万 $\mathrm { m } ^ { 3 }$ 。经处置后，可利用河砂为中砂，可利用量为 186.48 万 $\mathrm { m } ^ { 3 }$ 。河道平面走向基本按现状河线布置，堤线（岸线）基本沿现状河流水面、滩涂的边线布置，河道上游至下游设计纵比降依次为 1/4500、1/7000，与现状一致，河道开口线宽度为$4 0 \mathrm { m } ~ 2 9 0 \mathrm { m }$ ，两岸至水域用地边线。河道较窄段采用梯形断面，岸坡坡比1:2~1:2.5；河道开阔段降低河底高程，增加水体容积，采用梯形复式断面，坡比由上到下分别为 1:2.5、1:3。由于土方量较大，施工时，采用 $1 \mathrm m ^ { 3 }$ 挖掘机挖装，配 10t 自卸汽车运输。
