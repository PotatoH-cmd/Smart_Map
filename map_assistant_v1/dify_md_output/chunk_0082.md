豫潢砂许〔2023〕第 02 号采砂区域（傅营砂场）位于潢川县白露河傅营村可采区 BLHK1#下游可采区范围内，可采区桩号 $\mathrm { { K } } 1 3 \mathrm { { + } } 7 2 1 \sim$ $\mathrm { K } 1 5 { + } 6 1 2$ ，开采企业为潢川县光州城市建设投资有限公司。可采区长度为1891m ，开采面积 22.57 万 $\mathrm { m } ^ { 2 }$ 。平均开采宽度约为 $8 0 { - } 1 8 0 \mathrm { m }$ ，采砂期限为2023 年 12 月 15 日至 2024 年 6 月 5 日，许可开采总量为 40.0 万 $\mathrm { m } ^ { 3 }$ ，年度采砂控制总量 60 万吨。开采边线以距岸坡坡脚保留不少于 10m 安全距离，开采最陡边坡控制在 1:5 以内，规划纵坡 $0 . 4 6 \text{‰}$ ，开采控制底高程为47.94m-48.81m，采砂作业方式为混合采，采砂机具包括射吸式采砂船 3 艘（泵功率 128KW），挖掘机 1 台，装载车 2 台。根据现场监测情况，开采作业主要位于采区下游，作业区域较小，开采量不大，监测期间受旱情影响，采区水位较浅，故未进行无人船水下测量。
