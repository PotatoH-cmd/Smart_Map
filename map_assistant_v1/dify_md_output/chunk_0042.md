豫信平砂许〔2023〕第 01 号采砂区域位于浉河北岸 SH03#-1 可采区（桩号 $3 1 { + } 1 0 0 { - } 3 2 { + } 1 0 0 \ \cdot$ ），可采区为主河槽及左岸滩地，开采企业为信阳市平桥水利建设投资开发有限公司。采区位于平桥区五里街道办事处王水村，可采区长度为 1000m ，开采面积为 $0 . 1 8 \mathrm { k m } ^ { 2 }$ 。采砂期限为 2023 年 8 月 21日至 2024 年 6 月 14 日，该可采区河砂历史储量 201.47 万 $\mathrm { m } ^ { 3 }$ ，许可开采总量为 55.37 万 $\mathrm { m } ^ { 3 }$ ，85.82 万吨，现状高程 $5 4 . 4 \mathrm { m } { \cdot } 6 1 . 5 \mathrm { m }$ ，控制采砂高程为 $5 1 . 6 3 \mathrm { m } { - } 5 1 . 8 9 \mathrm { m }$ ，控制开采深度平均为 2.87m ，采砂作业方式为水采、旱采结合，开采区最陡边坡控制在 1:5。采砂机具为 3 艘采砂船（泵功率380KW）、1 立方米挖掘机 5 台、铲车 5 辆、自卸汽车 13 辆、提砂设备 3 套。
