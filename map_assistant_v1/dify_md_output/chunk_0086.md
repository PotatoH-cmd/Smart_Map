豫潢砂许〔2023〕第 04 号采砂区域（宋寨砂场）位于潢河上，包括老李店村可采区 HHK2#全部区域及上油岗乡宋寨村可采区 HHK3#全部区域，开采企业为河南水投光州现代水网有限公司。采砂期限为 2023 年12 月 27 日至 2024 年 3 月 31 日，许可开采总量为 21.79 万 $\mathrm { m } ^ { 3 }$ ，年度采砂控制总量 32.68 万吨。采砂作业方式为混合采，采砂机具包括射吸式采砂船 2 艘（泵功率分别为 120KW 和 195KW），提砂船 1 艘，挖掘机 1 台，装载车 2 台。 老李店村可采区 HHK2#，桩号 $\mathrm { K } 3 1 + 5 9 6 \sim \mathrm { K } 3 2 + 9 7 1$ ，采区长度 1375m ，开采面积为 10.92 万 $\mathrm { m } ^ { 2 }$ 。平均开采宽度约为 $6 0 { - } 1 0 0 \mathrm { m }$ ，开采控制底高程为$2 0 . 5 2 \mathrm { m } { - 2 0 . 8 9 } \mathrm { m }$ ，，控制开采量 20.05 万 $\mathbf { m } ^ { 3 }$ 。开采边线以距岸坡坡脚保留不少于 10m 安全距离，开采最陡边坡控制在 1：5 以内，规划纵坡 $0 . 2 7 \text{‰}$ 。 上油岗乡宋寨村可采区 HHK3#，桩号范围为 $\mathrm { K } 3 9 + 3 9 3 \sim \mathrm { K } 3 9 + 6 9 3$ ，长度 300m ，规划河道平均开采宽度 $1 2 0 \sim 1 6 0 \mathrm { m }$ ，开采面积 3.34 万 $\mathrm { m } ^ { 2 }$ ，平均开采深度为 0.52m ，现状深泓高程 $2 0 . 5 4 \sim 2 0 . 3 0 \mathrm { m }$ ，控制开采高程为$2 0 . 1 4 \sim 2 0 . 0 6 \mathrm { m }$ ，控制开采量 1.74 万 $\mathrm { m } ^ { 3 }$ 。开采边线以距岸坡坡脚保留不少于 10m 安全距离，开采最陡边坡控制在 1：5 以内，规划纵坡 $0 . 2 7 \text{‰}$ 。因该采区与老李店村采区共用宋寨临时堆砂场，且采砂量较小，不再单独对其配备采砂机具。
