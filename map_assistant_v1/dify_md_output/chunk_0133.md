豫息水砂许〔2023〕第 02 号批复采砂区域主要位于李家庄村可采区（ZGK4），采砂期限为 2023 年 3 月 1 日至 2023 年 12 月 31 日，许可开采总量为 54.90 万 $\mathrm { m } ^ { 3 }$ ，87.29 万吨，开采控制高程为 26.56-27.41m，采砂 作业方式为水采，采砂机具包括采砂船 5 艘（泵功率分别为 258KW、330KW、192KW、213KW、235KW），装载车 6 台。 李家庄村可采区位于八里岔乡李家村附近，在规划李家庄村可采区（ZGK4）范围内。采区位于界河右岸（桩号 ${ \mathrm { K } } 9 + 1 7 6 \sim { \mathrm { K } } 1 0 + 8 7 6 { \it \Delta \Psi } .$ ），开采长度为 1700m ，面积为 9.69 万 $\mathrm { m } ^ { 2 }$ ，深泓线高程为 29.50-29.71m，开采区边线以坡脚保留 $1 0 { - } 3 0 \mathrm { m }$ 安全距离，最陡边坡控制在 1:5 以内，控制开采高程为 $2 6 . 5 6 \mathrm { m } { - 2 7 . 4 1 } \mathrm { m }$ ，规划纵坡 $0 . 5 \text{‰}$ 。
