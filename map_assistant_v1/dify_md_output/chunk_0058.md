豫罗砂许〔2023〕第 04 号可采区名称为 LG10，开采企业为罗山县交运发展有限责任公司，位于竹竿河莽张镇天湖村郑洼村部分河段。桩号$3 9 + 4 0 0 \sim 4 4 + 4 5 0$ ，罗山县与光山县界河段左岸。本年度桩号 $3 9 \substack { + 4 0 0 } \sim$ $4 1 + 8 0 0$ 、 $4 2 + 2 0 0 \sim 4 3 + 2 0 0$ ，长 3400m ，宽 $7 7 \sim 1 8 7 \mathrm { m }$ ，开采前河底高程约45.1～49.3m、45.8～49.9m，控制开采高程 45.6～46.7m、 $4 6 . 8 \sim 4 7 . 3 \mathrm { m }$ ，年 度采砂控制总量 154.85 万吨。开采区边线以距岸坡保留 $3 0 \sim 1 0 0 \mathrm { m }$ 安全距离及河流中心线控制，起始端按规划比降 1:4 坡比控制进行开挖至控制开采底高程。开采作业方式为水采，批复作业机具为 10 艘采砂船（泵功率 350KW），装载车 4 台。
