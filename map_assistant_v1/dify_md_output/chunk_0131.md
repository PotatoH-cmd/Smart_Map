豫息水砂许〔2023〕第 01 号批复采砂区域包括景美店村可采区（ZGK1）和陈大洼村可采区（ZGK2）。许可采砂期限为 2023 年 3 月 1 日至 2023 年12 月 31 日，许可开采总量为 54.9 万 $\mathrm { m } ^ { 3 }$ ，年度采砂控制总量约 87.29 万吨，控制开采高程为 34.60-35.00m（景美店村 1#开采区），33.88-33.95m（景美店村 2#开采区），31.53-32.13m（陈大洼村开采区），采砂作业方式为水采加旱采，采砂机具包括采砂船 5 艘（泵功率 219KW 一艘、195KW三艘、338KW 一艘），挖掘机 6 台，装载车 13 台。 景美店村开采区位于八里岔乡景美店村附近，在规划的景美店村可采区（ZGK1）范围内，开采区位于界河右岸，开采区总长度为 948m ，总面积为 7.31 万 $\mathrm { m } ^ { 2 }$ ，该可采区又分为景美店村 1#开采区和景美店村 2#开采区两部分，为 2022 年实施方案重未开采区域，该区域批复采砂船两艘。 景美店村 1#开采区（桩号 $\mathrm { K } 0 \substack { + 0 0 0 } \sim \mathrm { K } 0 \substack { + 8 0 0 }$ ），开采区长度为 800m ， 宽度为 37.2-128.4m，面积为 5.81 万 $\mathrm { m } ^ { 2 }$ ，深泓线高程为 35.23-37.03m。开采区边线以坡脚保留 $1 0 { - } 3 0 \mathrm { m }$ 安全距离，开采最陡边坡控制在 1:5 以内，控制开采高程为 $3 4 . 6 0 \mathrm { m } \cdot 3 5 . 0 0 \mathrm { m }$ ，规划纵坡 $0 . 5 \text{‰}$ ，控制开采量为 11.43 万$\mathrm { m } ^ { 3 }$ 。 景美店村 2#开采区（桩号 $\mathrm { K } 2 + 1 0 5 \sim \mathrm { K } 2 \substack { + 2 5 3 }$ ）,开采区长度为 148m ，宽度为 $7 5 . 7 { \cdot } 9 6 . 5 \mathrm { m }$ ，面积为 1.50 万 $\mathrm { m } ^ { 2 }$ ，深泓线高程为 34.69-35.08m。开采区边线以坡脚保留 $1 0 { - } 3 0 \mathrm { m }$ 安全距离，开采最陡边坡控制在 1:5 以内，控制开采高程为 $3 3 . 8 8 \mathrm { m } { - 3 3 . 9 5 \mathrm { m } }$ ，规划纵坡 $0 . 5 \text{‰}$ ，控制开采量为 2.30 万$\mathrm { m } ^ { 3 }$ 。 陈大洼村开采区位于八里岔乡陈大洼村附近，在规划陈大洼村可采区（ZGK2）范围内，桩号 $\mathrm { K } 3 + 7 4 2 \sim \mathrm { K } 4 + 9 4 2 ( \ 2 0 2 2$ 年陈大洼村开采区下游），界河右岸，开采区长度为 1200m ，宽度为 56.7-219.7m，面积为 20.05 万$\mathrm { m } ^ { 2 }$ ，深泓线高程为 33.23-32.76m。开采区边线以坡脚保留 $1 0 { - } 3 0 \mathrm { m }$ 安全距离，开采最陡边坡控制在 1:5 以内，控制开采高程为 $3 1 . 5 3 \mathrm { m } { - 3 2 . 1 3 \mathrm { m } }$ ，规划纵坡 $0 . 5 \text{‰}$ ，控制开采量为 47.52 万 $\mathrm { m } ^ { 3 }$ 。该区域批复采砂船 3 艘。
