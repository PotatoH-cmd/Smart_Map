豫罗砂许〔2023〕第8 号采区位于LS12、LS13 可采区范围内，开采企业为罗山县交运发展有限公司。开采作业方式为水采，年度采砂控制总量为138.55万吨，批复的开采作业机具包括8艘采砂船（泵功率350KW），装载车4台，采砂许可有效期为 2023年05 月24 日-2024年05 月23 日。 LS12 位于周党镇（青龙村、闵湾村）。桩号： $4 8 + 4 0 0 \sim 5 0 + 3 0 0$ ，左右岸均在罗山县境内。本年度桩号 $5 0 \substack { + 0 0 0 - 5 0 + 3 0 0 }$ ，长 300m ，控制开采高程$5 0 . 7 ~ 5 0 . 9 \mathrm { m }$ 。 LS13 可采区位于周党镇（中山村、长安村）。桩号： $5 0 + 3 0 0 \sim 5 3 + 1 4 0$ ，左右岸均在罗山县境内。本年度桩号 $5 0 + 3 0 0 \sim 5 3 + 1 4 0$ ，长 2840m ，宽$5 8 ~ 9 3 \mathrm { m }$ ，河底高程约 $5 0 . 0 \sim 5 3 . 5 \mathrm { m }$ ，控制开采高程 $5 0 . 9 ~ 5 2 . 3 \mathrm { m }$ ，开采区边线以距岸坡保留 $3 0 ~ 1 1 0 \mathrm { m }$ 安全距离及河流中心线控制，起始端按规划比降1:4 坡比控制进行开挖至控制开采底高程。
