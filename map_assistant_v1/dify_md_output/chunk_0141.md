豫信砂许〔2023〕第 01 号许可采砂区域（坝下可采区）位于鲇鱼山水库坝下（水库大坝~S339 灌河大桥）规划范围。根据规划可采区范围为：鲇鱼山水库坝下 $2 3 0 0 \mathrm { m } \mathrm ~ \mathrm { S } 3 3 9$ 灌河大桥上 500m ，对应开采区桩号为$2 + 3 0 0 ~ 2 { + } 9 0 0$ ，长 600m ，宽 $4 0 0 ~ 5 0 0 \mathrm { m }$ ，现状河底高程 $7 2 . 9 0 ~ 7 3 . 4 1 \mathrm { m }$ ，以开采河床底部砂为主，控制开采高程 $7 0 . 9 ~ 7 1 . 1 { \mathrm { m } }$ ，平均采深 2.1m ，年度采砂控制总量为 25 万方，37.5 万吨。考虑到现状河岸为土质岸坡，右岸现状有堤防，年度开采范围距离现状岸坡左岸预留 50m 保护距离，右岸预留 100m 保护距离。批复开采期限为 2023 年 12 月 21 日到 2024 年 5 月 15 日，批复作业机具包括 3艘采砂船（泵功率420KW），装载车2台，挖掘机 3 台。
