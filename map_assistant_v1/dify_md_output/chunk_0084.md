豫潢砂许〔2023〕第 03 号采砂区域（林寨砂场）位于潢川县白露河黄堰村可采区 BLHK4#下游区域，可采区桩号 $\mathrm { K } 3 1 + 7 3 0 \sim \mathrm { K } 3 3 + 6 6 1$ ，开采企业为河南水投光州现代水网有限公司。可采区长度为 1931m ，开采面积为 21.12 万 $\mathrm { m } ^ { 2 }$ 。平均开采宽度 $7 0 { - } 2 1 0 \mathrm { m }$ ，采砂期限为 2023 年 12 月 27 日至 2024 年 6 月 5 日，许可开采总量为 44.73 万 $\mathrm { m } ^ { 3 }$ ，年度采砂控制总量67.09 万吨。开采控制底高程为 $3 3 . 7 9 \mathrm { m } \mathrm { - } 3 4 . 6 8 \mathrm { m }$ ，可采区边线以坡脚保留10m 安全距离，开采最陡边坡控制在 1:5 以内，规划纵坡 $0 . 4 6 \text{‰}$ 。采砂作业方式为混合采，采砂机具包括泵吸式采砂船艘（泵功率 330KW），运砂船 1 艘，挖掘机 1 台，装载车 2 台。
