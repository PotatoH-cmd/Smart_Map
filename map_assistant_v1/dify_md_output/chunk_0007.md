为保证产品质量，结合相关项目工作经验，我公司从组织保证措施、人员保证措施、设备投入保证措施、技术保证措施、资金保证措施、后勤保障措施及质量管理奖惩措施等方面加强保障，确保质量保证体系得以实施。 # （1）组织协调措施 为保证本次工作高质量完成，我公司根据工程的实际需要，成立了项目组，分工具体、明确。项目负责人可以统一调配各种资源，对项目进行全面管理，对发包人负责，协调人员、协调技术、资源配置、计划进度、质量控制等。专业负责人负责本专业的计划安排、人员分工、互提资料的验证，协调上下工序的关系；会同专业负责人进行专业技术论证、方案选定和成果的审定。专业组组长负责对成果进行校核。通过严密而又系统的组织协调措施，从而保证组织机构高效、快速运行，保证产品质量。 # （2）人员保证措施 我公司投入人员中，主要人员均多年从事遥感、测绘与地理信息系统以及计算机相关专业工作，业务水平高，工作能力强，经验丰富，完全能够把握产品质量。所有参加本项目人员统筹考虑是否同时参加公司承担的其他项目，以保证不与本项目工作发生冲突，影响本项目工作质量。 # （3）设备保证措施 根据工作实际情况，投入各类设备、仪器、软件等，这些仪器设备运行状态均良好，性能可靠，并有充足的后备资源可供调配，保证了工作进度计划的顺利实施。 # （4）技术保证措施 结合具体情况，制定本项目实施方案及管理办法，严格执行我公司质量管理体系文件，在项目运行过程中，从数据生产 编写 校核 审查核定 批准严格把关，并由质量、综合部定期检查，严格控制，保证产品质量。 # （5）关键质量控制措施 各专业之间技术接口处理，由项目负责人负责组织协商，项目专业负责人协调解决。上道工序所提资料应经校审后方可提供给下道工序，各专业之间互提资料应以书面形式提出。 对于关键性的资料、数据，根据情况应以会议的形式进行评审，会议由专业负责人主持，并形成评审纪要。 审查意见落实：各阶段的成果经审查后，针对每一阶段全面研究、落实审查意见提出的需解决的问题。 # （6）质量管理奖惩措施 严格执行我公司《质量管理办法》等奖惩措施，确保产品质量。
