## 一、项目概述

**map_assistant_v1** 是一个面向水利/采砂监管领域的地理信息智能助手系统，集成卫星影像分析、GIS 空间分析、AI 大模型协同、知识库检索等功能，提供从底图管理到智能问答的全链路解决方案。

## 五、核心模块详解

### 5.1 AI 智能体协同层

**IntentAgent**（意图代理）负责解析用户自然语言输入，提取意图类型和关键参数。支持多种意图分类：

| 意图类型 | 说明 | 触发词示例 |
|----------|------|-----------|
| MAP_QUERY | 地图查询 | "显示河道" / "加载高分影像" |
| SPATIAL_ANALYSIS | 空间分析 | "测量面积" / "缓冲区分析" |
| SAM_DETECTION | 目标检测 | "识别违建" / "检测采砂" |
| REPORT_GENERATION | 报告生成 | "生成报表" / "导出报告" |
| KNOWLEDGE_QUERY | 知识查询 | "什么是可采区" |
| WEATHER_QUERY | 气象查询 | "明天天气" |

**TaskExecutor**（任务执行器）基于 LangGraph 状态图，将意图拆解为多步任务链，协调工具调用、LLM 推理、结果回传。

### 5.2 SAM 目标检测引擎

三阶段级联检测管道，结合 VLM 视觉理解和 SAM 分割：

```
瓦片图像 → [阶段1] VLM 快速分类(640px缩略图) → 无目标则跳过
              ↓ 有目标
           [阶段2] VLM bbox 检测(1280px全尺寸) → 置信度过滤
              ↓
           [阶段3] VLM 逐框验证裁剪 → 最终结果
              ↓
           GeoJSON → 地图渲染 + SHP 下载
```

**可调阈值**（前端面板实时调节）：

| 阈值 | 默认值 | 语义 |
|------|--------|------|
| 分类阈值 | 0.45 | 低于此值整张瓦片跳过 |
| 候选框阈值 | 0.65 | bbox 置信度过滤 |
| 二次确认阈值 | 0.75 | 裁剪后严格复核 |
| 自动放行阈值 | 0.90 | 同时满足上述验证阈值时跳过 LLM 调用 |

### 5.3 地图引擎（双地图并存）

| 特性 | Leaflet (2D) | CesiumJS (3D) |
|------|-------------|---------------|
| 场景 | 日常 GIS 操作 | 三维地形分析 |
| 底图 | 卫星/OSM/ArcGIS | Cesium Ion / 自定义地形 |
| 矢量 | GeoJSON + MVT 切片 | 3D Tiles / GeoJSON |
| 标注 | 动态抽稀（10,000点上限） | GPU 实例化渲染 |
| 绘制 | Leaflet.Draw | 自定义绘制 |

### 5.4 GeoServer 图层服务

通过 Docker 部署的 GeoServer 2.26.2 提供标准化 OGC 服务：
- **WMS**: 动态渲染图层
- **WFS**: 矢量要素查询
- **WMTS**: 预缓存瓦片加速
- **PostGIS 存储**: overlay 和 public schema 分层管理

### 5.5 知识库系统

文档处理管道：
```
原始文档 → Dify MD 分块 → RAGFlow 向量化 → 语义检索
                                              ↓
                              用户提问 → 向量检索 → LLM 增强回答
```

### 5.6 前端核心交互

| 组件 | 核心能力 |
|------|----------|
| MapComponent | 2D 地图初始化、图层切换、动态标注、视口同步 |
| CesiumComponent | 3D 地球加载、地形分析、双地图联动 |
| SAMPanel | SAM 检测参数配置、实时进度、结果预览、SHP 下载 |
| TileManager | 图层增删改、样式编辑、透明度调节 |
| KnowledgeBaseManager | 知识库可视化管理、文档上传、检索测试 |

## 七、数据流

### 7.1 对话流程
```
用户输入 → IntentAgent 意图识别 → TaskExecutor 拆解任务
    → 调用对应 Tool → LLM 生成回复 → SSE 流式回传前端
```

### 7.2 SAM 检测流程
```
前端选择区域 → POST /api/sam-detect → sam_predict.py 子进程
    → Ollama VLM 三阶段推理 → GeoJSON 回传 → Leaflet 渲染
    → 用户确认 → POST /api/sam-download → GeoPandas → ZIP(SHP)
```

### 7.3 地图瓦片加载
```
浏览器请求瓦片 → Nginx 缓存检查
    ├── 命中 → 直接返回
    └── 未命中 → 后端代理 → ArcGIS/GeoServer 源站 → 缓存
```
