# SAM 双时相遥感影像变化检测 — 技术方案

## 1. 概述

变化检测功能用于对比同一地理区域在两个不同年份的高分遥感影像，自动识别新增/消失的地物（如建筑物），支持 2023/2024/2025 三年影像的任意两两对比。

**核心文件**:
| 文件 | 职责 |
|------|------|
| `backend/main.py` | FastAPI 端点 `/api/sam-change-detect`，子进程调度 |
| `backend/tools/sam_predict.py` | 变化检测全流程（瓦片下载→SAM推理→对比→验证） |
| `frontend/src/components/SAMPanel.jsx` | 前端年份选择 + 变化检测按钮 + 分层渲染 |

**依赖环境**: conda env `sam`，Python 路径 `/home/server/miniconda3/envs/sam/bin/python`

## 4. 阶段详解

### 4.1 瓦片下载 (`fetch_tiles_for_bbox`)

**输入**: bbox `(minx, miny, maxx, maxy)` EPSG:4326, year, zoom=15

**步骤**:

1. **经纬度→瓦片坐标** (`_latlon_to_tile`)，使用标准 Slippy Map 公式：
   ```
   n = 2^zoom
   x = floor((lon + 180) / 360 * n)
   y = floor((1 - asinh(tan(lat)) / π) / 2 * n)
   ```
   - `x1, y2 = tile(maxy, minx)` → 西北角
   - `x2, y1 = tile(miny, maxx)` → 东南角
   - **关键**: y2 ≤ y1 (y=0 在北极，向南递增)，循环必须 `range(y2, y1+1)`

2. **瓦片数控制**: 若 tile_count > 64，降一级 zoom 重新计算

3. **下载**: 逐瓦片 HTTP GET，空白瓦片（<500 bytes）用透明占位替换。忽略 SSL 证书错误（自签名）

4. **拼接**: Pillow `Image.paste()` 将 256×256 瓦片拼接为单张大图，输出 `merged_{year}.png`

5. **地理参考**: 根据 NW 和 SE 瓦片坐标计算经纬度范围，写入 `.pgw` world file

**输出**: `(image_path, (minx, miny, maxx, maxy))`

### 4.2 SAM 目标检测 (`main`)

**输入**: GeoJSON geometry, 提示词, `custom_image_path`, `custom_bounds`

**模式**: 使用 `custom_image_path` 参数直接加载已拼接的瓦片影像，跳过本地 TIF 裁剪。

SAM 后端为 **Ollama**（`gemma4:31b` 模型），流程：
1. **分类阶段**: 将影像缩放到 classify_size (640px)，调用 Ollama 判断是否包含目标 + 估算数量
2. **检测阶段**: 若确认有目标，调用 SAM 分割 + 建筑色彩增强
3. **输出**: GeoJSON FeatureCollection，每个 feature 含 `id`, `prompt`, `area_m2`, `area_mu`

### 4.3 几何对比 (`compare_detections`)

**输入**: `geojson_a` (年份A), `geojson_b` (年份B), `iou_threshold=0.10`

**目的**: 匹配两套 SAM 检测结果的同一地物，容忍边界抖动。

**三层递进匹配**:

| 阶段 | 方法 | 参数 | 说明 |
|------|------|------|------|
| 1 IoU | 直接重叠比 | threshold ≥ 0.10 | 同一建筑，边界基本一致 |
| 2 缓冲区 IoU | EPSG:3857 下 expand 5m | buffered IoU ≥ 0.20 | 边界轻微漂移的同一建筑 |
| 3 质心距离 | WGS84 测地线距离 | ≤ 25m | SAM 边界差异极大但中心点近 |

每层匹配后记录 `match_method` 属性（`iou`/`buffer_iou`/`centroid`）。

**未匹配图斑的语义**:
- `year_a(早)` 有但 `year_b(晚)` 无 → `removed`（蓝色/消失）
- `year_b(晚)` 有但 `year_a(早)` 无 → `added`（红色/新增）

前端渲染颜色映射:

| change_type | 前端颜色 | 含义 |
|-------------|----------|------|
| `added` | 🔴 红色 | 新增建筑（晚年份出现） |
| `removed` | 🔵 蓝色 | 消失建筑（早年份存在） |
| `unchanged` | ⚪ 灰色 | 无变化（两年份均检测到） |

### 4.4 图像交叉验证 (`_verify_changes_with_images`)

**目的**: 过滤 SAM 检测不一致导致的假变化。SAM 对同一建筑因影像色彩/光照差异可能产生完全不同的多边形边界，导致几何匹配失败。

**方法**: 对每个标记为 `added`/`removed` 的候选变化图斑：

1. **地理坐标→像素坐标**: 根据影像的 world file 将多边形边界框转到两幅影像的像素空间
2. **提取图像块**: 从两幅影像中分别裁剪对应区域
3. **尺寸对齐**: 若两幅影像分辨率略有差异，用 `cv2.resize` 对齐
4. **计算 MAD**: 逐像素 RGB 平均绝对差异
   ```
   MAD = mean(|patch_a - patch_b|)  # 范围 [0, 255]
   ```
5. **阈值判定**:
   - **MAD < 30** → 像素很相似，SAM 只是漏检 → 改标为 `unchanged`（假变化）
   - **MAD ≥ 30** → 像素明显不同 → 确认真实变化，保留原标签

**验证结果记录**:
- `match_method: "image_verify"` (假变化纠正)
- `verify_mad: <浮点数>` (记录 MAD 值供调试)

## 5. 输出数据格式

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": { "type": "Polygon", "coordinates": [...] },
      "properties": {
        "id": 8,
        "prompt": "建筑物",
        "area_m2": 3110.72,
        "area_mu": 4.666,
        "year": 2023,
        "change_type": "unchanged",
        "match_method": "iou",
        "year_a": 2023,
        "year_b": 2025
      }
    },
    ...
  ],
  "metadata": {
    "year_a": 2023,
    "year_b": 2025,
    "prompt": "建筑物",
    "elapsed_s": 36.0,
    "features_a": 91,
    "features_b": 65,
    "features_change": 145
  }
}
```

### properties 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `change_type` | string | `added` / `removed` / `unchanged` |
| `match_method` | string | `iou` / `buffer_iou` / `centroid` / `image_verify` |
| `verify_mad` | float | 图像验证的 MAD 值 (仅 unmatched 图斑) |
| `year` | int | 该图斑来源年份 |
| `year_a` / `year_b` | int | 匹配年份 (仅 unchanged) |
| `area_m2` / `area_mu` | float | 面积 (平方米/亩) |

## 6. API 接口

### `POST /api/sam-change-detect`

**请求体**:
```json
{
  "geometry": { "type": "Polygon", "coordinates": [...] },
  "prompt": "建筑物",
  "year_a": 2023,
  "year_b": 2025,
  "fast_mode": true,
  "demo_mode": false
}
```

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `geometry` | GeoJSON Polygon | 必填 | 检测区域 (EPSG:4326) |
| `prompt` | string | 必填 | 目标提示词 |
| `year_a` | int | 2024 | 基准年份 (2023/2024/2025) |
| `year_b` | int | 2025 | 对比年份 (2023/2024/2025) |
| `fast_mode` | bool | true | 快速模式 (降低分辨率) |
| `demo_mode` | bool | false | 超快速演示模式 |

**超时**: 1200 秒 (20 分钟)

**进度查询**: `GET /api/sam-progress/{task_id}`

## 7. 前端集成

**组件**: `SAMPanel.jsx`，在 SAM 识别面板中集成了变化检测开关。

**操作步骤**:
1. 进入「🎯 SAM识别」面板
2. 在地图上绘制检测区域
3. 输入检测目标提示词（如"建筑物"）
4. 点击「变化检测」开关打开
5. 选择两个对比年份 (2023/2024/2025)
6. 点击「变化检测 20XX vs 20YY」按钮
7. 等待检测完成，结果分层渲染到地图

**结果渲染**:
- 红色多边形边框 + 半透明红填充 → `added` (新增)
- 蓝色多边形边框 + 半透明蓝填充 → `removed` (消失)
- 灰色多边形边框 + 半透明灰填充 → `unchanged` (无变化)
- 右下角自动显示图例 (15 秒后自动消失)

## 10. 关键参数与调优

| 参数 | 位置 | 当前值 | 说明 |
|------|------|--------|------|
| `zoom` | `fetch_tiles_for_bbox` | 15 | 瓦片缩放级别 |
| `tile_count_max` | `fetch_tiles_for_bbox` | 64 | 最大瓦片数，超出降 zoom |
| `iou_threshold` | `compare_detections` | 0.10 | IoU 匹配阈值 |
| `buffer_meters` | `compare_detections` | 5.0m | 缓冲区半径 |
| `centroid_dist_threshold` | `compare_detections` | 25.0m | 质心距离阈值 |
| `mad_threshold` | `_verify_changes_with_images` | 30 | MAD 假变化判定阈值 |
| `subprocess_timeout` | `main.py` | 1200s | 子进程超时 |

> **MAD 阈值调优**: 降低该值会减少假变化过滤（更保守），提高该值会更多判为假变化（更激进）。
