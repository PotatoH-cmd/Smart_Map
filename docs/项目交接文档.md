## 1. 项目概览

### 1.1 项目是什么

**豫水智能一张图（Smart Map）**：面向水利勘测与河道采砂监管的 **LLM Agent 驱动的 GIS 智能助手**——"一句话，驱动一张图"。用户以自然语言对话，系统自动完成意图识别 → 任务规划 → 工具调度 → 地图渲染/数据查询/知识检索/报告生成。

业务场景：河道采砂监管、河道红线侵占识别、采区测深数据查询、无人机影像管理、采砂监测周/月报自动生成、水利政策知识问答（150+ 篇规范文档）。

### 1.2 关键数字（2026-09 现状）

| 项 | 数值 |
|---|---|
| 后端代码 | Python ≈1.4 万行（FastAPI + LangGraph + 36 个工具模块） |
| 前端代码 | React ≈1 万行（Leaflet 2D + Cesium 3D + 管理面板群） |
| API 路径 | OpenAPI 94 条（/docs 实时查看） |
| 工具 | 工具中台目录 **43 个**（Native 15+ / MCP 自动发现 / Skill 1 / HTTP） |
| 意图 | intents.yaml 13 类 |
| 无人机影像 | drone_imagery registry 31 条（固始/潢川/罗山/商城各采区 MBTiles） |
| 3D Tiles | 2 个（test_tileset 测试 + jiaxian-beiruhe 郏县北汝河） |
| 知识库 | LlamaIndex 本地向量库（150+ 篇规范）；RagFlow 远程兜底 |
| 测试 | pytest 91 用例全绿（CI 三 job 门禁） |
| 后端进程重启 | 65 次 / 前端 132 次（见 §11 风险 2） |

### 1.3 功能全景

| 能力 | 一句话说明 | 入口 |
|---|---|---|
| 对话即操作 | 自然语言 → 2D/3D 图层加载、视角飞行、打点 | 对话面板 + Leaflet/Cesium |
| 数据问答 | NL→SQL 直查 PostGIS（采深/许可/统计） | postgresql_tool |
| 知识问答 | 混合检索 RAG：Milvus(向量)+BM25(jieba)→RRF→rerank（本机实际降级 Simple 向量） | knowledge_base_tool |

## 4. 系统架构

四层结构 + 双微服务（详见 README.md 架构图，这里给文字速览）：

```text
┌─ 前端 React 18（:3004）─────────────────────────────────────────────┐
│  对话面板(SSE) · Leaflet 2D · Cesium 3D(WS /ws/cesium)              │
│  GeoLibre iframe(深链注入) · Falcon/切片/知识库/工具中台管理面板      │
└───────────────┬──────────────────────────────────────────────────────┘
                │ HTTP · SSE · WebSocket（CRA dev proxy → :8006）
┌───────────────▼──────────────────────────────────────────────────────┐
│ 后端 FastAPI（:8006）main.py 纯装配 → routers/ 10 域                  │
│  agents/：IntentAgent → AgentHarness → TaskExecutor(LangGraph)       │
│   RunEngine（Run 生命周期/事件流/检查点/断线恢复）                     │
│  记忆：context_manager(短期) · fact_memory(用户事实) · 知识库(长期)    │
└──────┬──────────────────────┬─────────────────────────┬──────────────┘
       │ TOOL_HUB_URL         │ INTENT_SERVICE_URL      │ 数据访问
┌──────▼──────┐      ┌────────▼────────┐      ┌─────────▼───────────┐
│ Tool Hub    │      │ Intent Service  │      │ PostGIS(远程)         │
│ :8011       │      │ :8010           │      │ SQLite(sessions.db)  │
│ Native×15   │      │ 无业务枚举意图   │      │ LlamaIndex 向量库     │
│ MCP 发现×N  │      │ 目录 TTL 拉取    │      │ (Milvus 未装→Simple) │
│ HTTP / Skill│      │ (宕机自动回退    │      │ Kuzu 图谱(实验)      │
│             │      │  进程内实现)     │      │ GeoServer/QGIS MCP   │
└─────────────┘      └─────────────────┘      └──────────────────────┘
模型层：Qwen 系列 DashScope（LLM/embedding-v3/rerank）· Falcon(8765 常驻 GPU) · SAM3
```

### 4.1 对话主链路（一条消息怎么走完）

1. 前端 `POST /chat/stream`（SSE）→ `routers/chat.py`；
2. IntentAgent：LLM 结构化意图识别；约 60 条**快速关键词路由**（`config/fast_routes.json`）先于 LLM 命中（省时省钱）；用户事实记忆注入意图分析；
3. AgentHarness 按意图分派：MapAgent / DataAgent / KnowledgeAgent / ReportAgent / GeneralAgent（兜底）；RulesGateway 合规与参数校验；
4. LangGraph 节点：intent → tool（可多步）→ summarize；工具经 ToolHub（进程外 8011）或本地注册表调用，事件实时写入 RunEngine 并 SSE 推送（`run_events`）；
5. 模型总结生成回复 + 前端指令：`map_commands`（2D）、`cesium_commands`（3D）、`charts`（ECharts）、`text`；
6. 会话成功后异步抽取用户稳定事实写入 `user_facts`；
7. **断线自愈**：前端重连 `/chat/stream?run_id=…` + `/api/run/{id}/events` 补拉事件，检查点恢复。

### 4.2 工具中台与意图服务（微服务）

- **Tool Hub :8011**：工具唯一事实源。`tools/` 自动扫描 Native（qwen_agent 装饰器）→ tools.yaml 覆盖元数据 → `mcp_servers` 段自动发现远端 MCP（qgis :8036、postgres :8009）→ `http_tools` 声明 REST → `skills.yaml` 复合技能。前端控制台可试跑。
- **Intent Service :8010**：意图识别无业务倾向，从 ToolHub 目录 + intents.yaml 拉取意图清单。
- **降级**：两服务任一不可用 → 主后端日志出现 `fallback local`，自动用进程内实现，对话不中断（对应 pytest 用例 test_service_fallback.py）。

### 4.3 记忆系统（三层）

- 短期：SQLite 消息表持久化；上下文预算最近 8 轮 × 160 字（env 可调）；工具结果 4000 字预算按优先级裁剪；>12 轮触发 LLM 滚动摘要（60s 去抖）；MemorySaver 200 线程 LRU；Run 数据 7 天 TTL 清理。
- 长期：知识库双路召回（向量 Milvus + BM25 jieba）→ RRF 融合 → gte-rerank-v2 精排（`KB_RERANK` 开关）。**本机未装 Milvus → 实际自动降级 SimpleVectorStore（llama_index_storage/ 本地 JSON）**。
- 用户事实：`user_facts` 表，管理 API `GET/DELETE /api/memory/facts`。

## 9. 核心业务链路说明

### 9.1 采砂监测报告（最高频业务，坑多——先读防错指南）

链路：`caisha_report_tool`（site_name 如"郝楼砂场"）→ 拼接 `ceshen` 测深 + 许可信息 + 无人机影像比对 → 报告截图（后端截图接口或前端 capture）→ `templates/caisha_monitor_template.docx` 填充 → 输出 `backend/static/reports/` → 在线预览/下载。

- 批量跑报告：`backend/scripts/batch_caisha_reports.py`（日志 backend/logs/batch_caisha_reports.log）。
- **必读防错手册**：[docs/采砂监测报告生成问题复盘与防错指南.md](docs/采砂监测报告生成问题复盘与防错指南.md)（历史多轮翻车复盘：模板错位/字段缺失/影像张冠李戴等，改模板或工具前必读）。
- 模板维护：`scripts/create_template.py` / `update_template.py`，模板文件 `backend/templates/*.docx`。

### 9.2 Falcon 遥感识别（GPU 链路）

前端框选 → `/api/falcon-detect`（routers/falcon.py 起子进程）→ `falcon_detect.py` 取影像切瓦片 → query 中英翻译（内置高频词表 + qwen-flash 兜底 3 候选）→ falcon-service:8765 逐瓦片推理（子进程模式冷启动归零）→ mask 融合 → 多边形 GeoJSON → 实例上图统计 → 主候选 0 实例自动换备选重试 → `/api/falcon-requery` 逐实例精修 → `/api/falcon-download` SHP 打包。

### 9.3 空间分析（QGIS MCP）

`qgis_mcp_tool` 自然语言 action → `agents/qgis_workflows.py` 匹配 recipe → docker qgis-mcp:8036 内 QGIS 插件执行（加载 /gis_data、/data、/uploads 的数据）→ 结果 GeoJSON 写 `backend/static/geojson/`（容器 /output 共享）→ 上图。**QGIS Recipe 开发指南**：[docs/QGIS_Recipe开发指南.md](docs/QGIS_Recipe开发指南.md)。

### 9.4 切片与三维资产发布

- TileManager 面板 → `services/tile_manager/`：MBTiles/矢量瓦片/3D Tiles 的 registry + 构建任务（osgb→glb 转换在 `three_d.py`）+ 发布；`registry.json` 是注册表 SSOT（含 alt_offset、auto_ground_clamp 等元数据），**新数据集发布会自动登记**。
- 模块加载时 `_auto_register_existing_3dtiles_async()` 自动注册已存在目录。

### 9.5 知识库灌库（新增文档流程）

1. 把 md/规范文档放到资料目录；2. 用 `backend/scripts/ingest_*.py`（ingest_caisha_md.py / ingest_jiance_md.py / ingest_shishifangan_multi.py 等）灌入 LlamaIndex（content_hash 去重、同名替换、persist 防抖）；3. 前端 KnowledgeBaseManager 验证检索；4. 备份由每日 cron 承担。

### 9.6 数据导入（一次性任务脚本）

- 坐标点：`scripts/import_rtk_dat.py`（RTK dat 解析 → rtk_points/GeoJSON）。
- 矢量：`scripts/import_geojson.py`。
- 采砂/监测资料灌库见上；`scripts/kb_rebuild.py` 用于灾后重建（详见 §10.5）。

### 10.6 常见故障速查

| 现象 | 排查路径 |
|---|---|
| 对话报错/无响应 | ① `pm2 logs map-assistant-backend` 看 stack；② 检查 DASHSCOPE_API_KEY 是否有效（401）；③ `curl /api/memory/facts` 验证 DB |

| 前端页面反复白屏/自动重启 | dev server 模式 + 1G 内存上限，看 pm2 restart 次数（§11 风险 2） |
| 高分影像底图空白 | nginx /gf-tiles 代理缓存（gis95.yskc.com 外网可达性） |
| GeoLibre 打不开 | docker geolibre:8090 是否在、CORS、geolibre_projects json 是否损坏 |
| vector-data 报错 | 曾在 tiles.py 修过列查询前置 bug（properties 路径），升级代码后需重启生效 |
| 报告缺数据 | 读 9.1 的防错指南；检查 ceshen 表 site 名拼写、模板占位符 |
