# 无人机影像发布注意事项

> 本文件总结历次发布中遇到的问题和最佳实践，后续新增砂场影像时请逐条核对。

---

## 一、原始数据检查（发布前）

### 1. 确认影像真实坐标系（最重要）

**问题**：GeoTIFF 内部写入的 EPSG 代码可能不准确（标 4548 实际是 4547），导致影像偏移到外省。

**检查方法**：

```bash
# 查看 GeoTIFF 的元数据
gdalinfo 文件.tif | grep -E "PROJCRS|AUTHORITY"

# 查看影像四至坐标
gdalinfo 文件.tif | grep -A4 "Corner Coordinates"
```

**判断标准**：

| 实际位置 | 中央经线 | 正确 EPSG | 经度范围（参考） |
|---------|---------|-----------|-----------------|
| 固始县 | 114°E | EPSG:4547 | ~115.4°E – ~115.9°E |
| 罗山县 | 114°E | EPSG:4547 | ~114.1°E – ~114.6°E |
| 潢川县 | 114°E | EPSG:4547 | ~114.9°E – ~115.4°E |
| 息县 | 114°E | EPSG:4547 | ~114.5°E – ~115.0°E |
| 商城县 | 114°E | EPSG:4547 | ~115.3°E – ~115.6°E |

> **技巧**：如果 gdalinfo 显示的角点经度在 ~118°E 附近（偏移约 3°），说明影像虽标 4548 但实际是 4547。直接用 gdalwarp 重新投影即可修正。

### 2. 确认影像波段数

**问题**：单波段（灰度）TIF 发布后显示为黑白，且透明区域变白底。

```bash
gdalinfo 文件.tif | grep "Band "
# Band 1 → 单波段（需加 -dstalpha）
# Band 1, Band 2, Band 3 → 三波段 RGB（正常）
```

### 3. 确认是否需要镶嵌

一个砂场文件夹内若有多个 `.tif` 文件，需先镶嵌为一个再发布。

## 二、发布流程

### 单文件（无镶嵌）

直接在 `publish_raster_async` 中指定 `source_srs`：

```python
publish_raster_async(
    source_path=tif_path,
    layer_key="luoshan_xxx",
    name="某某采区",
    min_zoom=10,
    max_zoom=22,
    opacity=0.95,
    overwrite=True,
    source_srs="EPSG:4547",  # ← 明确指定，不依赖 GeoTIFF 内部标头
)
```

### 多文件需镶嵌

```bash
# 步骤1：构建虚拟栅格
gdalbuildvrt -overwrite merged.vrt 文件1.tif 文件2.tif

# 步骤2：转为单幅 GeoTIFF
gdal_translate -of GTiff -co TILED=YES -co COMPRESS=DEFLATE -co BIGTIFF=YES merged.vrt merged.tif
```

### 批量发布策略

- **串行执行**：逐个发布，不要同时启动多个任务
- **限制线程**：builders.py 已设置 `NUM_THREADS=4`，不要改大
- **每个文件预计耗时**：3–10 分钟（取决于文件大小）

## 三、图层命名规范

格式：`{县名拼音}_{砂场关键词拼音}`

示例：
- `luoshan_qinglong_minwan` — 罗山·青龙闵塆采区
- `gushi_guandaochao` — 固始·灌河道超可采区
- `shangcheng_shiniu` — 商城·石牛村采区

县名拼音对照：
- 固始 → `gushi`
- 罗山 → `luoshan`
- 潢川 → `huangchuan`
- 息县 → `xixian`
- 商城 → `shangcheng`

## 五、常见问题速查

| 现象 | 原因 | 解决 |
|------|------|------|
| 影像偏到江苏（~118°E） | GeoTIFF 标 4548 实际 4547 | 重发，`source_srs="EPSG:4547"` |
| 图像黑白+白底 | 单波段 TIF，无透明通道 | 重发，确保 `-dstalpha` 生效 |
| 发布时服务器卡死 | 并发数太高 | 改为串行，`NUM_THREADS=4` |
| 图层名混乱 | 未按命名规范 | 发布时指定 `layer_key` |
| 多文件文件夹只发了一个 | 未先镶嵌 | 用 gdalbuildvrt + gdal_translate |
